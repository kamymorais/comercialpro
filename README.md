# ComercialPro

Base inicial do ComercialPro, criada com Next.js, TypeScript, App Router, Tailwind CSS e estrutura em `/src`.

## Comandos

```bash
npm run dev
npm run lint
npm run build
```

Servidor local esperado:

```txt
http://localhost:3000
```
