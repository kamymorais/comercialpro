# COMERCIALPRO — PLANO DE CODIFICAÇÃO EM 20 ETAPAS

Este plano deve ser seguido em ordem.

Objetivo: criar uma aplicação simples, leve, modular, moderna e instalável no celular como PWA.

======================================================================
ETAPA 01 — CRIAÇÃO DO PROJETO
======================================================================

Criar projeto Next.js com:

- TypeScript.
- App Router.
- Tailwind.
- ESLint.
- src directory.

Comando sugerido:

npx create-next-app@latest comercialpro

Configurações esperadas:

- src/app
- TypeScript ativo.
- Tailwind ativo.
- App Router ativo.

ETAPA 05 — SEED DO ADMIN
======================================================================

Criar seed inicial para ADMIN.

Dados mínimos:

- fullName: Administrador
- username: admin
- passwordHash: hash da senha definida
- requestedRole: MANAGER ou CONSULTANT apenas se enum exigir, mas ideal ajustar para permitir ADMIN no seed
- role: ADMIN
- status: APPROVED

Melhor opção:
Adicionar ADMIN também em RequestedRole ou criar requestedRole opcional.

Recomendação:
requestedRole pode ser nullable para usuário criado diretamente como ADMIN.

ETAPA 19 — RESET DIÁRIO ÀS 19H
======================================================================

Criar rota:

/api/cron/reset-daily

Regras:

- Proteger com CRON_SECRET.
- Verificar se já existe ResetLog SUCCESS para operationalDate.
- Se já existe, retornar SKIPPED.
- Se não existe, registrar SUCCESS.
- Não apagar histórico.
- Garantir que após 19h getOperationalDate passe para o próximo dia.

Cron sugerido:
- 19h America/Sao_Paulo = geralmente 22h UTC.
- Configurar conforme hospedagem.

vercel.json exemplo:

{
  "crons": [
    {
      "path": "/api/cron/reset-daily",
      "schedule": "0 22 * * *"
    }
  ]
}

Importante:
A lógica principal de reset deve depender de getOperationalDate, não de deletar dados.
