- 2026-07-08 - Etapa 04 concluída: implementada a extração real de texto do PDF com Python. Criada a Vercel Python Function api/margin_extract.py (convenção BaseHTTPRequestHandler, compatível com o runtime Python da Vercel), que recebe os bytes brutos do PDF, usa pypdf para extrair texto página a página, identifica campos candidatos (bruto/descontos/líquido/margemPdf) e linhas de rubrica por padrão de texto (sem calcular nada), e retorna erro amigável quando o texto extraído é insuficiente (PDF provavelmente escaneado). Criado requirements.txt na raiz com "pypdf". A função é protegida por um segredo compartilhado MARGIN_EXTRACT_SECRET (novo, adicionado a .env.example), enviado pelo Next.js via header Authorization: Bearer — sem esse segredo a função não é utilizável publicamente. Criado src/services/marginExtraction.service.ts (server-only, nunca importado por componente client) com extractMarginPdfText, que monta a URL absoluta de /api/margin_extract a partir da própria requisição, envia o PDF como corpo bruto (Content-Type: application/pdf, não multipart) e trata erros de rede/config como falha genérica (502) e falha de extração como 422. Endpoint POST /api/verificador-margem/upload (Etapa 03) ajustado para, após validar sessão/perfil/tipo/tamanho, chamar extractMarginPdfText e retornar file + extraction + nextStep="CALCULATION_PENDING". Expandidos os tipos em src/types/margin.ts (MarginPageText, MarginCandidateFields, MarginRubricLine, MarginExtractionResult).
